BIENVENUE SUR TRADING BOTPremière connexion ? Configure ton compte en 6 étapesPC Windows pour le moteur · Téléphone ou PC pour le tableau de bord⌄

Prépare un PC Windows connecté à Internet et un compte MT5 démo en USD. Le mot de passe du site sert à ouvrir ce tableau de bord ; tes identifiants MT5 restent dans MT5.

  1. 01

    Prépare ton PC

    Installe Python 3.10 ou plus récent, en 64 bits, avec le lanceur py. Ouvre MetaTrader 5 et connecte-toi à ton compte démo USD.

    Télécharger Python pour Windows ↗
  2. 02

    Autorise la connexion MT5

    Active Algo Trading. Dans Outils → Options → Expert Advisors, décoche l’option qui désactive le trading via l’API Python externe. Le libellé peut varier selon la langue de MT5.

    MT5 doit rester ouvert sur le bon compte.

  3. 03

    Installe le connecteur v4

    Télécharge le ZIP ci-dessous, puis clic droit → Extraire tout. Dans le dossier extrait, lance INSTALLER_ET_LANCER.bat. Laisse l’installation se terminer ; elle peut installer le tunnel Cloudflare.

    ↓ Connecteur Windows v4
  4. 04

    Relie le PC au site

    Le connecteur affiche une URL de liaison et une clé de liaison. Copie-les dans les deux champs de la section Connexion, puis clique sur Relier mon PC.

    Aller aux champs de connexion ↓

    Garde la fenêtre du connecteur ouverte et la clé privée.

  5. 05

    Vérifie avant de démarrer

    Compare le numéro de compte, le serveur et le solde avec MT5. Garde les paramètres par défaut pour le premier essai : risque 0,5 %, limite quotidienne 1 %, ratio 2. Vérifie le symbole EUR/USD et son éventuel suffixe.

    Commence en mode supervisé, puis clique toi-même sur Démarrer. Relier le compte ne lance aucun ordre. Le bot attend un signal valide.

  6. 06

    Utilise ton téléphone

    Ouvre ce même site sur ton téléphone, connecte-toi et saisis l’URL et la clé du PC. Chaque navigateur se relie séparément. Le PC, MT5 et le connecteur restent allumés.

    Pour fermer le site pendant l’exécution, coche Continuer quand le site est fermé avant Démarrer. Sinon, les nouvelles entrées se mettent en pause après 25 secondes sans tableau de bord.

Les prochaines fois

Ouvre MT5, puis lance LANCER.bat. Le connecteur repart à l’arrêt. Après un nouveau tunnel, remplace l’URL et la clé dans Connexion.

Un problème pendant la configuration ?
  • Python introuvable : vérifie l’installation de Python 64 bits et du lanceur py, puis relance l’installation.
  • Cloudflare introuvable après installation : ferme la fenêtre du connecteur puis relance-la.
  • Compte refusé : ouvre un compte démo USD dans MT5. Les comptes réels et concours ne sont pas acceptés.
  • Liaison impossible : vérifie Internet, garde MT5 et le connecteur ouverts, puis recopie l’URL et la clé actuelles sans espaces.
  • Marché fermé ou prix périmés : attends le retour des cotations. L’absence de signal ne signifie pas que la liaison est en panne.

Le bouton Arrêter bloque les nouvelles entrées ; il ne clôture pas les positions déjà ouvertes.

Pour les premiers tests

Le PC, MT5 et le connecteur doivent rester ouverts. Après redémarrage du connecteur, le bot est toujours arrêté ; il ne reprend pas automatiquement les ordres. En mode supervisé, les nouvelles entrées sont suspendues après 25 secondes sans tableau de bord actif. Le mode autonome, à choisir avant Démarrer, permet de fermer le site : le moteur reste sur le PC. Les positions conservent leurs protections chez le courtier. Une coupure du tunnel nécessite une reconnexion.

Les comptes réels et concours sont refusés par le connecteur. Risque prévu plafonné à 1 % par position et limite quotidienne à 3 % pour cette version de test. Les gaps et conditions d’exécution peuvent dépasser le risque prévu. Le moteur n’ouvre aucun ordre simplement en reliant le PC : clique sur Démarrer quand tu es prêt.

Connecteur v4 nécessaire pour le mode autonome et l’historique. Installation Windows et exécutions sur ton terminal démo encore à vérifier. Aucun gain garanti. Le laboratoire de backtest reste disponible séparément.
