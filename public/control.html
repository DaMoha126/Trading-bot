Pour les premiers tests

Le PC, MT5 et le connecteur doivent rester ouverts. Après redémarrage du connecteur, le bot est toujours arrêté ; il ne reprend pas automatiquement les ordres. En mode supervisé, les nouvelles entrées sont suspendues après 25 secondes sans tableau de bord actif. Le mode autonome, à choisir avant Démarrer, permet de fermer le site : le moteur reste sur le PC. Les positions conservent leurs protections chez le courtier. Une coupure du tunnel nécessite une reconnexion.

Les comptes réels et concours sont refusés par le connecteur. Risque prévu plafonné à 1 % par position et limite quotidienne à 3 % pour cette version de test. Les gaps et conditions d’exécution peuvent dépasser le risque prévu. Le moteur n’ouvre aucun ordre simplement en reliant le PC : clique sur Démarrer quand tu es prêt.

Connecteur v4 nécessaire pour le mode autonome et l’historique. Installation Windows et exécutions sur ton terminal démo encore à vérifier. Aucun gain garanti. Le laboratoire de backtest reste disponible séparément.
